[ ../ ](/) # Analog habits I sometimes find myself relying a little too much on technology for what it's worth. I have in recent years trying to slowly progress towards building more analog habits. Below is a list of my current progression. - \* Taking notes on paper - \* Reading newspapers - \* Using a physical calendar - \* Using a physical alarm clock - \* Using a physical map - \* Using a physical calculator - \* Using an analog watch - \* Using an analog timer - \* Drawing and sketching on paper
